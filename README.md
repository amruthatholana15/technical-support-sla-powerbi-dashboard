# Technical Support SLA & Performance Analytics Dashboard

## Project Overview

This Power BI project analyzes technical support ticket data to monitor support performance, ticket trends, and SLA compliance.

The dashboard provides visibility into ticket volumes, resolution performance, first-response SLA performance, weekly and monthly trends, and ticket distribution across countries.

## Business Objectives

- Monitor overall technical support ticket volume
- Track open, closed, and resolved tickets
- Analyze Resolution SLA performance
- Analyze First Response SLA performance
- Identify monthly and weekly ticket trends
- Compare support ticket volumes across countries
- Enable interactive analysis using filters and slicers

## Dashboard KPIs

- Total Tickets
- Resolved Tickets
- Open Tickets
- Closed Tickets
- Resolution SLA Compliance
- First Response SLA Compliance

## Data Preparation

Power Query was used to prepare and transform the dataset before analysis, including:

- Data type validation
- Data cleaning and transformation
- Date preparation
- Creation of supporting fields for analysis

## Project Overview

- Closed Tickets

## Data Preparation

Power Query was used to prepare and transform the dataset before analysis, including:

- Data type validation
- Data cleaning and transformation
- Date preparation
- Creation of supporting fields for analysis

## Data Modeling

A relational data model was created using fact and dimension tables.

The ticket data was used as the central fact table and connected to supporting dimension tables using one-to-many relationships.

This structure allows filters from dimension tables to correctly filter ticket-level data and dashboard measures.
